About Nova

Nova is a web portal that combines an unblocked-game arcade with a full web proxy. It's powered by Ultraviolet — one of the most established open-source proxies — running on the modern Wisp protocol with the Epoxy transport.

How it works

When you search or open a game, the page registers a service worker that intercepts requests for the proxy prefix. Every request to a real site is re-encrypted, sent over a websocket (/wisp/) to this server, and streamed back to you. To the network you're on, it looks like ordinary traffic to one site. Cookies, storage, websockets, and most site features work inside the tunnel because the service worker rewrites them transparently.

Playing games

The arcade titles are embedded straight from their publishers, so they run in-place without the proxy — that means full speed and low ping. Anything else on the web (Flash-era sites, other portals, Discord, YouTube) opens through the proxy instead. You can choose where games open — the in-page player or a separate about:blank window — in Settings.

Staying under the radar

Settings has a few tricks worth knowing:

Tab cloak

Swaps the tab title and favicon to look like Google Classroom, Drive, Docs, Gmail and more. It applies to every page here and to cloaked about:blank windows.

Panic key

Set a key (default `) that instantly replaces the page with Google Classroom — or any URL you choose — from anywhere on the site. It only triggers when you're not typing in a text field, so it won't fire while you're searching.

about:blank mode

Opens content in a blank window that keeps no history entry for the game itself. Pop-up blockers can interfere; if it doesn't open, allow pop-ups for this site.

FAQ

Why is a game not loading?

First reload the page — the service worker and websocket need a moment on first launch. If a specific game stays black, its publisher may have dropped embed support; use the home search to open that game's website through the proxy instead.

Does it work on school Chromebooks?

It runs in any modern browser without installing anything. If this whole site is blocked on your network, you'll need a different deployment address — check the TitaniumNetwork community for alternatives.

Is anything saved on a server?

No. Favorites, history, settings and custom shortcuts are stored only in your browser's localStorage. You can export or wipe them in Settings at any time.
